# Heads, in 50 Lessons

A single-page drawing course for men's and women's heads, written as short lessons with an animated diagram and a drawing canvas. Built for an iPad with Apple Pencil, but it works on a phone.

The lessons follow the order and principles of Andrew Loomis's *Drawing the Head and Hands* (1956), retold in my own words. No pages or text from the book are included here.

- No accounts, no server. Progress and drawings are saved in the browser on your device.
- Use Export backup on the home screen to save everything to a file.
- Add to Home Screen in Safari to run it like an app.

Status: lessons 1 and 2 are written. The rest are in progress.
